# Changelog

What changed for people who use VitaPact, newest first. Each version is a
[GitHub release](https://github.com/Reiner409/vitapact/releases) with the files to install.

## 1.0.0 · 2026-10-24

The first stable version, for Windows, Android and iPhone.

- **iPhone.** The release now includes an iOS app (`.ipa`). Until VitaPact is on the App Store,
  install it with AltStore or Sideloadly using your own Apple ID.
- **Accessibility.** Every screen and dialog is checked with axe at phone and desktop widths, and
  the keyboard focus ring is visible on every control, text fields included.
- **Tested end to end.** Coming back after a missed week, private notes and two friends swapping
  reports are covered by end-to-end tests that fail on any network request.
- **Documentation.** A README with what the app does, how to run it and a 50-second trailer, plus
  the GPL-3.0 licence text and a contributing guide.

## 0.2.0 · 2026-10-19

- **Android.** The release includes an Android APK next to the Windows installer and portable,
  and the screens fit phones.
- **Rotating stake.** A group can rotate its stake every week from a fixed list.

## 0.1.0 · 2026-10-18

The first public build for Windows (installer and portable).

- **Today:** log sleep, training, clean eating and sun with a score that fills up as you answer,
  a greeting by the hour and the week at a glance.
- **Sunday weigh-in:** asked on Sunday before breakfast, with a reminder until Tuesday.
- **Week:** weekly score, one card per habit, day details and the weight over 12 weeks.
- **Report:** a signed weekly report as a PNG with a QR code, saved or copied to the clipboard.
- **Friends:** add a friend's report from a file or the clipboard, groups with stakes, weekly and
  monthly rankings, comebacks, who pays the weekend and a friend's history.
- **Noteboard:** private notes with tags and search, optionally locked with a password.
- **Settings:** goals, groups, key fingerprint, export and import of all data, delete everything.
